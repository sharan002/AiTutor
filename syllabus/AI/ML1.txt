# NumPy Arrays

NumPy-na, numbers-a fast-aa handle panna use aagura Python library.
Oru NumPy array-la ellaa values-um same type-aa irukkum, adhanaala oru vaati-la ellaa values-kum calculation panna mudiyum.
Loop ezhudha vendiyadhilla; array * 2 nu ezhudhinaale ovvoru value-um double aagum.

#code#
import numpy as np

marks = np.array([45, 62, 78, 90, 55])
print("Marks:", marks)
print("Average:", marks.mean())
print("Highest:", marks.max())
print("Marks after 5 bonus:", marks + 5)
#/code#

Mean-na average. Standard deviation-na values evlo spread aagi irukku-nnu sollum.

#code#
print("Spread (std):", round(marks.std(), 2))
print("Above average:", marks[marks > marks.mean()])
#/code#

# Your First Model

Oru model-na, data-la irundhu kathukitta oru formula.
Linear Regression, points-oda nadula oru straight line poduthu; andha line vachu pudhu value-va predict pannum.
fit-na model-ku kathukudukkaradhu, predict-na kathukitta pinnadi answer solradhu.

#code#
from sklearn.linear_model import LinearRegression

X = data[["hours_studied"]]   # input (features)
y = data["marks"]             # answer (target)

model = LinearRegression()
model.fit(X, y)

print("Marks for 7 hours:", model.predict(pd.DataFrame({"hours_studied": [7]}))[0].round(1))
#/code#

Intha model oru straight line-a kathukitturukku. Slope-na, oru extra hour-ku evlo marks yerudhu-nnu sollum.

#code#
print("Each extra hour adds about", round(model.coef_[0], 2), "marks")
print("Starting marks:", round(model.intercept_, 2))
#/code#
